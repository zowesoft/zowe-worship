# Spoken script for the confidence calibration set.
#
# One clip per line:  <written references> :: <sentence to read aloud>
# Leave the reference empty for a clip that must produce nothing.
#
# Read the sentence the way it would be said from the pulpit: no reading the
# punctuation, no pausing to announce "colon". The point is to capture the
# spoken forms the detector has to score (chapter/verse in words, connectors,
# bare numbers), through a real mic, with the room's own noise.
#
# Keep clips short (one or two sentences) so the sweep has many independent
# detections; add more lines rather than longer ones.
